# FileFlow - Smart File Organizer

A local web application built with Python and Flask. It organizes files in a demo folder by type, provides live statistics, and includes filename search.

## Run in VS Code

```bash
python -m pip install -r requirements.txt
python app.py
```

Open the localhost address shown in the terminal, usually `http://127.0.0.1:5000`.
